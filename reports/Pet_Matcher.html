Pet Matcher¶

Project Overview¶

Pet Matcher is a project aiming to make the pet adoption process in Bulgaria simpler, kinder, and more effective.
Its goal is to help people and animal shelters find the best possible match between adopters and pets, based on their lifestyles, needs, and personalities.

The idea works a bit like a dating app — but instead of connecting people with each other, it connects people with pets.
By combining basic information about shelter animals (such as age, breed, and temperament) with the preferences of potential adopters, Pet Matcher aims to make adoption decisions easier and more confident.

Every year, many animals shelters wait for someone to take them home. Unfortunately, some are never adopted, while others are returned because they weren’t the right fit.
Pet Matcher hopes to change that by giving adopters a better understanding of which pets might suit them best — and by helping shelters present their animals in a more personal and meaningful way.

Objective¶

The main goal of Pet Matcher is to support smarter and more successful pet adoptions.
The project focuses on:

  • Helping people find pets that fit their lifestyle and home environment.
  • Supporting shelters in reducing the number of returned adoptions.
  • Encouraging long-term, happy relationships between people and their pets.

This notebook begins with the first technical step of that goal — understanding and cleaning the data collected animal shelters.

Central Research Question¶

How can we use shelter animal data and adopter preferences to predict a match percentage that increases the chance of animals finding their forever homes and adopters finding their best-matched pets?

This research question guides the analytic approach, focusing on practical, explainable AI that benefits both shelter organizations and adopters.

Analytical Approach¶

This project is primarily a regression problem, aiming to predict a continuous value (match percentage).
Different machine learning methods will be evaluated to find a balance between accuracy and interpretability, so shelter staff can understand why a specific pet was recommended.

Potential models include:

  • Linear Regression > baseline interpretability
  • Decision Trees > rule-based and explainable
  • Random Forest > robust and accurate with feature importance
  • K-Nearest Neighbors (KNN) > for personalized recommendations

Evaluation metrics:

  • Mean Absolute Error (MAE)
  • R² Score
  • Top-K Accuracy (checking if the chosen pet appears in the model’s top recommendations)

Dataset Description¶

The dataset used here was collected from public animal shelters in Bulgaria, prepared and shared by one of them.
The data contains descriptive attributes of animals such as:

Category Example Attributes
Identification Animal ID, name, species
Physical Traits Breed, size, weight, color
Health Vaccination, sterilization, medical conditions
Behavior Temperament, activity level, socialization
Shelter Data Admission date, stay duration, adoption status

Data Translation¶

The original dataset was entirely in Bulgarian.
Due to the large amount of data, ChatGPT was used only for translation from Bulgarian to English.
No data manipulation or modification was made - only translation to ensure accessibility for further analysis and model training.

Cramér’s V Correlation Matrix — Evaluation¶

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from scipy.stats import chi2_contingency

# Select categorical columns (exclude dates and numeric)
cat_cols = df.select_dtypes(include="object").columns.tolist()
if "arrival_date" in cat_cols:
    cat_cols.remove("arrival_date")

# Function to compute Cramér's V
def cramers_v(x, y):
    confusion = pd.crosstab(x, y)
    chi2 = chi2_contingency(confusion, correction=False)[0]
    n = confusion.sum().sum()
    phi2 = chi2 / n
    r, k = confusion.shape
    phi2corr = max(0, phi2 - ((k - 1)*(r - 1))/(n - 1))
    rcorr = r - ((r - 1)**2)/(n - 1)
    kcorr = k - ((k - 1)**2)/(n - 1)
    return np.sqrt(phi2corr / min((kcorr - 1), (rcorr - 1)))

# Build correlation matrix
corr_matrix = pd.DataFrame(
    np.zeros((len(cat_cols), len(cat_cols))),
    index=cat_cols,
    columns=cat_cols
)

for col1 in cat_cols:
    for col2 in cat_cols:
        if col1 == col2:
            corr_matrix.loc[col1, col2] = 1.0
        else:
            corr_matrix.loc[col1, col2] = cramers_v(df[col1], df[col2])

# Visualize
plt.figure(figsize=(10,8))
sns.heatmap(corr_matrix, annot=True, cmap="coolwarm", fmt=".2f", square=True)
plt.title("Cramér’s V Correlation Matrix (Categorical Features)")
plt.tight_layout()
plt.show()

Modeling¶

In this project, I apply a predictive modeling approach to estimate how well each adopter fits with a shelter animal based on their traits, preferences, and lifestyle.
Unlike my previous project, which used a content-based recommender, this system uses machine learning classification models to predict a match percentage — a continuous score between 0 and 1 that represents compatibility.

Why this approach?¶

  • Explainability: Models like Linear Regression and Decision Trees are easy to interpret, allowing shelter staff to understand why certain pets are recommended.
  • Adaptability: The approach can be extended later by integrating more adopter features or behavioral data.
  • Quantitative scoring: Produces a numerical compatibility score that enables ranking multiple pets for a single adopter.
  • Balance between accuracy and interpretability: Using several models ensures comparison across both simple and complex learners.

# ============================================
# Pet Matcher (Static Column Weights) + Model Benchmarks
# ============================================
import numpy as np
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.metrics import accuracy_score, roc_auc_score

# Models
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.neighbors import KNeighborsClassifier

# ----------------------------
# Load & normalize
# ----------------------------
df = pd.read_csv(ROOT / 'data/bulgarian_shelter_animals.csv')
df.columns = df.columns.str.strip().str.lower()

# Normalize yes/no-like columns
def norm_bool_col(s):
    mapping = {"y":"yes","yes":"yes","true":"yes","1":"yes",
               "n":"no","no":"no","false":"no","0":"no"}
    return s.astype(str).str.strip().str.lower().map(lambda v: mapping.get(v, v))

for c in ["good_with_kids","good_with_pets","sterilized","vaccinated"]:
    if c in df.columns:
        df[c] = norm_bool_col(df[c])

# Numeric age
if "age_years" in df.columns:
    df["age_years"] = pd.to_numeric(df["age_years"], errors="coerce")

# ----------------------------
# Feature set + target
# (ordered by your importance list)
# species > breed > age > gender > temperament > size > activity_level > health_status > good_with_kids > good_with_pets > sterilized > vaccinated
# ----------------------------
ordered_features = [
    "species","breed","age_years","gender","temperament","size","activity_level",
    "health_status","good_with_kids","good_with_pets","sterilized","vaccinated"
]
features = [c for c in ordered_features if c in df.columns]

if "adoption_status" not in df.columns:
    raise ValueError("adoption_status column is required for model benchmarking.")

# Target: 1 if adopted
y = df["adoption_status"].astype(str).str.lower().str.contains("adopt").astype(int)
X = df[features].copy()

# ----------------------------
# Preprocess
# ----------------------------
num_cols = [c for c in features if X[c].dtype.kind in "ifc"]
cat_cols = [c for c in features if c not in num_cols]

preprocess = ColumnTransformer(
    transformers=[
        ("num", Pipeline([("imp", SimpleImputer(strategy="median")),
                          ("sc", StandardScaler())]), num_cols),
        ("cat", Pipeline([("imp", SimpleImputer(strategy="most_frequent")),
                          ("oh", OneHotEncoder(handle_unknown="ignore", sparse_output=False))]), cat_cols),
    ],
    remainder="drop"
)

# ----------------------------
# Train/Test split (80/20)
# ----------------------------
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)

# ----------------------------
# Train the four models
# ----------------------------
models = {
    "LinearRegression": Pipeline([("prep", preprocess),
                                  ("model", LinearRegression())]),
    "DecisionTree":     Pipeline([("prep", preprocess),
                                  ("model", DecisionTreeClassifier(random_state=42))]),
    "RandomForest":     Pipeline([("prep", preprocess),
                                  ("model", RandomForestClassifier(
                                      n_estimators=300, random_state=42, n_jobs=-1))]),
    "KNN":              Pipeline([("prep", preprocess),
                                  ("model", KNeighborsClassifier(n_neighbors=15))]),
}

print("=== CLASSIFICATION ACCURACY (test) ===")
for name, pipe in models.items():
    pipe.fit(X_train, y_train)
    if name == "LinearRegression":
        # Regression as baseline score -> threshold at 0.5
        y_score = np.clip(pipe.predict(X_test), 0, 1)

def sim_cat(a, b):
    if pd.isna(a) or pd.isna(b): return 0.0
    return 1.0 if str(a).strip().lower() == str(b).strip().lower() else 0.0

def sim_num(a, b, tol=1.0, max_diff=10.0):
    if b is None or pd.isna(b) or pd.isna(a): return 0.0
    try:
        a = float(a); b = float(b)
    except:
        return 0.0
    diff = abs(a - b)
    if diff <= tol: return 1.0
    if diff >= max_diff: return 0.0
    return 1.0 - (diff - tol) / (max_diff - tol)

def pet_match_top7_static(user_input, top_k=7, return_cols=None):
    """
    user_input: dict with one chosen value per column (from dropdowns later), e.g.:
      {
        "species": "Dog", "breed": "Mixed", "age_years": 2.0, "gender": "Female",
        "temperament": "Friendly", "size": "Medium", "activity_level": "High",
        "health_status": "Healthy", "good_with_kids": "yes", "good_with_pets": "yes",
        "sterilized": "yes", "vaccinated": "yes"
      }
    """
    keys = [k for k in WEIGHTS.keys() if k in df.columns and k in user_input]
    total_weight = sum(WEIGHTS[k] for k in keys if WEIGHTS[k] > 0)

    scores = np.zeros(len(df), dtype=float)
    for i, row in df.iterrows():
        s = 0.0
        for k in keys:
            w = WEIGHTS[k]
            if TYPE_MAP[k] == "num":
                s += w * sim_num(row.get(k, np.nan), user_input[k])
            else:
                s += w * sim_cat(row.get(k, np.nan), user_input[k])
        scores[i] = (s / total_weight) if total_weight > 0 else 0.0

    out = df.copy()
    out["match_%"] = (scores * 100).round(1)

    if return_cols is None:
        return_cols = [c for c in [
            "name","species","breed","gender","size","color","age_years",
            "temperament","activity_level","health_status","good_with_kids","good_with_pets",
            "sterilized","vaccinated","adoption_status","arrival_date"
        ] if c in out.columns]

    return (out.sort_values("match_%", ascending=False)
              [["match_%"] + return_cols]
              .head(top_k)
              .reset_index(drop=True))

Linear Regression Baseline model that captures simple linear relationships. Easy to interpret and quick to train.

Evaluation Metrics¶

Since this project’s goal is to evaluate how well each model predicts adoption likelihood (compatibility), the following metrics were used:

  • Accuracy: Percentage of correct predictions on the test set.
  • AUC (Area Under the Curve): Measures the model’s ability to distinguish between adopted and not-adopted animals.
  • Training vs Testing Comparison: Helps identify overfitting or underfitting patterns.

Project Evaluation¶

The Pet Matcher project successfully demonstrates how data-driven approaches can be used to predict compatibility between adopters and shelter animals.
Through the use of machine learning models and weighted similarity scoring, the system offers personalized pet recommendations based on multiple attributes such as breed, temperament, activity level, and age.

Strengths¶

  1. Practical Application:
    The concept has direct real-world value - shelters could use it to simplify and speed up the adoption process by matching potential adopters with suitable animals.

  2. Explainability:
    Using interpretable models like Linear Regression and Decision Trees allows both adopters and shelter staff to understand why a particular match was suggested.

  3. Balanced Modeling:
    The comparison between simple and complex models (KNN, Random Forest, etc.) provides insight into which algorithms generalize better given the dataset size and structure.

  4. Efficient Design:
    The static weighting system ensures that the recommendation process remains fast and user-friendly - an essential aspect for real-time applications in shelters or websites.

Limitations and Challenges¶

  1. Dataset Size and Diversity:
    The model’s current accuracy is limited by the dataset’s scope. With more diverse and larger-scale data, especially from multiple shelters, the predictions could become more robust.

  2. Feature Imbalance:
    Some features (like species and breed) have stronger influence due to being more directly tied to adoption likelihood, while softer features (like temperament or health) may not be equally represented.

  3. Binary Outcome Simplification:
    Adoption is treated as a yes/no variable, but in reality, many external factors - adopter lifestyle, home environment, shelter location - affect decisions but aren’t included in the model.

  4. Overfitting in Tree-Based Models:
    The Decision Tree and Random Forest models achieved perfect accuracy on training data but lower accuracy on testing, indicating that the models memorized patterns rather than generalized them.

  5. Limited Personalization:
    The current static weighting system, although practical, does not dynamically adapt to individual adopter preferences — which might vary significantly from one user to another.

Real-World Potential¶

If integrated into a shelter’s website or mobile platform, Pet Matcher could:

  • Help adopters find pets that best fit their personality and lifestyle.
  • Reduce animal return rates by promoting better compatibility.
  • Support shelter staff in prioritizing animals for potential adoption.

However, real-life adoption decisions involve emotional, financial, and situational factors that cannot be fully captured by data alone.
Thus, this system should assist rather than replace human judgment — acting as a recommendation aid rather than an automated decision-maker.

Next Steps and Future Improvements¶

  1. Data Expansion:
    Collect larger, more varied datasets from multiple shelters and regions to improve model robustness and representation.

  2. Dynamic Weight Adjustment:
    Instead of static weights, introduce a feedback mechanism where adopters can indicate what matters most to them — making the system more personalized and adaptive.

  3. Feature Enrichment:
    Include behavioral data, activity logs, or adopter lifestyle information to improve matching accuracy.

  4. Bias Mitigation:
    Review model outputs to ensure no unfair bias towards certain breeds, ages, or genders is present.

  5. Real-World Testing:
    Pilot the system with an actual shelter or small adoption platform to evaluate its impact on adoption rates and user satisfaction.

  6. User Interface Integration:
    Develop a simple, interactive UI where users select preferences (via dropdown menus) and view their top 7 pet matches visually with photos and compatibility scores.

Overall, Pet Matcher demonstrates the potential of combining data analysis and machine learning to improve the animal adoption process.
While the current results show moderate accuracy, the framework lays a solid foundation for real-world application.
